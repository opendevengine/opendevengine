Documentation / GitHub connection

GitHub connection

Use a GitHub App and select repositories explicitly. A GitHub CLI login is not imported.

Create and install an App

  1. Start with --data-dir and unlock your operating system’s credential vault.
  2. Open Settings → GitHub → Connect GitHub.
  3. Review the private App manifest on GitHub and choose Create. It requests Contents and Pull requests read/write, and Metadata read.
  4. Install the App on the repositories you want to use.

The App ID and private key go into the OS vault. There is no plaintext fallback.

Use an existing App

Choose Use an existing GitHub App and provide its App ID, slug and private key. With the default port, its Setup URL must be http://127.0.0.1:8765/api/github/callback. If you change --port, update the callback port too.

Older read-only Apps need Contents and Pull requests write permissions enabled on GitHub and accepted for the installation before publication can work.

Two independent switches

Use in Ask
Allows indexing and inclusion in answers and plans.
Allow changes
Allows implementation and draft PR publication for that repository. It does not publish anything by itself.

Enable both for a session’s writable repository. Losing access or disabling a permission can block work even when an older plan was ready.
