Documentation / Security model

Security model

Designed for one user on their own computer. Local-first does not mean every model runs locally.

Loopback, single user

The server binds to 127.0.0.1 and checks request hosts and origins. It has no login and must not be exposed on a network or the internet. This is not a shared-host or multi-tenant service.

Credentials and source

GitHub App keys and provider API keys live in macOS Keychain, Linux Secret Service or Windows Credential Manager. If secure storage is unavailable, setup is blocked. There is no plaintext fallback.

Local-only mode is on by default. Sending source to a remote model requires disabling it and opting the relevant provider or execution profile in. The one exception you can set is --ollama-url: its IP address is treated as local, so only point it at a machine you control. Connection tests send synthetic content. The selected data directory contains source-bearing records, so protect it and any backups.

Read-only Ask and indexing

Ask reads indexed snapshots and calls configured models; it never executes repository commands or changes files. Indexing reads committed source without running install or build scripts, excluding credential-like and generated files. Exclusions reduce exposure; inspect content before enabling external processing.

Precisely what is isolated

Each session’s repository copy and commands run in a container with --network none, all capabilities dropped, a read-only root filesystem and memory, CPU, process and time limits. Images must already be present locally. A host checkout alone is not an isolation boundary.

The Claude Code CLI itself runs on the host, in an empty private temporary directory. Its built-in tools, hooks, plugins, settings, memory and slash commands are disabled; it acts only through brokered tools into the container. The CLI still needs network access to Anthropic and uses your own login. The agent receives the saved plan and permitted source. Treat this as read/write access to a repository copy and review the diff.

Stopping requests termination and confirms the agent and container are gone, or reports containment failure. Isolation depends on your OS, Docker and the coding CLI; this does not protect against someone already controlling your account, machine or vault.

Publication and authority

Only explicitly enabled repositories can receive changes, on new opendevengine/… branches as draft PRs. The app never merges or pushes to a default branch. Repository content and model output cannot widen a plan’s scope or permissions. User-managed skills, plugins/MCP and memory are not available yet.

Report a vulnerability

Use Security → Report a vulnerability on the GitHub repository. Do not post an unfixed vulnerability in a public issue, discussion or PR. Include version or commit, operating system, reproduction steps and observed impact.
