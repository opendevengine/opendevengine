Getting started

Run a local workspace, then choose the repositories it can read.

Requirements

Install Python 3.10 or later with SQLite FTS5 and Git. Python.org and Homebrew Python builds include FTS5. Docker and an installed, logged-in Claude Code CLI are needed for implementation sessions, not for exploring the demo.

Install and run

git clone https://github.com/opendevengine/opendevengine.git workspace
cd workspace
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[full]'
opendevengine --data-dir ./workspace-data

In your browser, open http://127.0.0.1:8765. Keep the terminal running. The example uses a data directory inside this checkout; choose a private directory outside any repository you intend to index for everyday use. This example uses a POSIX shell; activate the virtual environment using your shell’s equivalent on other systems.

Try the demo first

python3 -m opendevengine

With no --data-dir, the app uses memory and four bundled sample repositories. Nothing persists after exit. The demo runs without optional packages. Persistent storage is required for GitHub credentials and implementation sessions.

Your first repository

  1. Open Settings → GitHub and connect a GitHub App.
  2. On Repositories, enable Use in Ask for a repository.
  3. Wait for a usable index, then attach the repository in Ask and ask where a feature lives.
  4. Open a citation to inspect the indexed source. Generate a plan when you are ready to describe a change.

To explore explicit local checkouts instead:

opendevengine --repo web=../storefront --repo api=../orders-api

These paths must be Git checkouts with a committed HEAD. Repeat --repo NAME=PATH up to eight times. Local and demo sources support Ask; they do not grant GitHub publication permission.
